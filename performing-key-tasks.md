# 🧾 Performing Key Tasks

This section walks you through the most common actions you’ll perform in **CyberShield Security Suite**. Each task includes clear, step-by-step instructions so you can accomplish it quickly and confidently.

***

### Task 1: Run a Full System Scan

Running a full system scan checks your device for viruses, malware, and suspicious files.

1. From the left sidebar, click **🦠 Antivirus**.
2. In the **Scan Options** panel, select **Full Scan**.
3. Click **Start Scan**.
4. Wait for the scan to complete — progress is shown on the screen.
5. Review the scan results under **Summary Report**.
6. Click **Resolve All** to remove or quarantine any detected threats.

💡 _Tip:_ You can continue working while CyberShield scans in the background.

### Task 2: Schedule Automatic Scans

To ensure ongoing protection, set up regular automatic scans.

1. Go to **⚙️ Settings → Scan Scheduler**.
2. Click **Add New Schedule**.
3. Choose the **Scan Type** (Quick, Full, or Custom).
4. Select the **Frequency** (Daily, Weekly, or Monthly).
5. Choose the **Day & Time** for the scan.
6. Click **Save Schedule**.

✅ _CyberShield will now run scans automatically based on your chosen schedule._

<figure><img src=".gitbook/assets/cybershield Scheduler.png" alt="CyberShield Scan Scheduler window showing fields to add a new schedule with scan type set to Full, frequency set to Weekly, and day and time set to Monday, 9:00 AM."><figcaption><p><em>Figure 5: Configuring a new automatic scan schedule in CyberShield.</em></p></figcaption></figure>

***

### Task 3: View and Export Security Reports

CyberShield automatically records threat and scan data in detailed reports.

1. From the sidebar, select **📊 Reports**.
2. Choose the report type you want to view — _Threat Summary_, _Scan History_, or _Compliance Report_.
3. Use the **Date Filter** to narrow results.
4. To export, click **Export → PDF** or **Export → CSV**.
5. Save the file to your preferred location.

> **💡 Tip:** Exported reports can be shared with your IT or compliance team.

<figure><img src=".gitbook/assets/CyberShield Reports.png" alt="CyberShield Reports module displaying options to select report type as Threat Summary and date filter as Last 7 days, with export buttons for PDF and CSV formats."><figcaption><p><em>Figure 6: Exporting security reports from the CyberShield Reports module.</em></p></figcaption></figure>

***

### Task 4: Configure the Firewall

Control which applications and services can access your network.

1. Navigate to **🧱 Firewall → Rules**.
2. Click **Add New Rule**.
3. Choose **Allow** or **Block** for specific applications or ports.
4. Assign a name to your rule and click **Save**.
5. Review active rules in the list to ensure proper configuration.

> ⚠️ **Caution:** Blocking system-critical services may disrupt connectivity — only modify advanced rules if you’re an experienced user.

***

### Task 5: Update Virus Definitions

Keeping your virus definitions up-to-date ensures protection against new threats.

1. Click **⚙️ Settings → Updates**.
2. Click **Check for Updates**.
3. Wait for CyberShield to connect to the update server.
4.  Once complete, you’ll see:

    ✅ _Virus definitions are up to date._

> **💡 Tip**: Enable **Automatic Updates** so CyberShield downloads new definitions daily.

✅ You’re all set with the basics — now take CyberShield’s protection to the next level.
